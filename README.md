# Farradyne — Home Page v1

Single-page review build for Farradyne, a technology venture studio serving businesses and founders in the United States.

## Stack

Next.js App Router, TypeScript, Tailwind CSS 4, Framer Motion. Static export is enabled for portability and Vercel hosting.

## Development

Install dependencies with `npm ci`, then run `npm run dev`. `npm run build` validates TypeScript and produces the deployable static export in `out/`.

## Scope

Home only: navigation, hero, positioning, four capabilities, five projects, venture/client model, process, founder, insights, contact CTA and footer. Navigation uses anchors. Email and Telegram links are live; no form backend or tracking is installed. Articles are explicitly marked coming soon. No additional pages or live domain configuration are included.

## Brand and content

The supplied final brand image is preserved in `public/brand-reference.png`; the original F symbol is displayed using a CSS crop, without redrawing it. Project covers are editorial typography, not photos of completed deliverables. Founder uses initials until an approved portrait is supplied. Project descriptions and founder history follow the approved brief and should be checked at content review. The preview is marked noindex.
